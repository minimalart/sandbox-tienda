# Mercatto Product List Video

Remotion motion graphic for the Mercatto product list feature.

## Preview

```bash
pnpm --filter @repo/mercatto-product-list-video preview
```

## Render MP4

```bash
pnpm --filter @repo/mercatto-product-list-video build
```

Or from this folder:

```bash
npx remotion render src/index.ts ProductListVideo out/mercatto-product-list.mp4 --codec=h264 --overwrite
```

## Voice-over script

Managing thousands of products gets messy fast.
Mercatto gives your team a clean, centralized product list built for real commerce operations.
Search across large catalogs, filter by source, status or channel, and inspect every product with its variants, prices, metadata and images.
From imported retail products to multi-channel catalogs, Mercatto keeps everything organized, searchable and ready to sell.
